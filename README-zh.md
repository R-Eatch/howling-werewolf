# 月厄狼人 · Forge 1.20.1

[English](README.md)

这里是《月厄狼人》**Minecraft 1.20.1** 版的源码，分支 `1.20.1-forge`。

| | |
|---|---|
| Mod 版本 | **1.3.8** |
| Minecraft Java 版 | 1.20.1 |
| Forge | 47.4.16 或更新版本 |
| Java | 17 |

用 `./gradlew build` 构建，JAR 位于 `build/libs/howlingwerewolf-1.3.8-forge.jar`。服务端和每个客户端需安装同一版本。

1.3.8 修复了 Punchy! 3.2b 下变身后空手时第一人称手臂重叠的问题，以及 Not Enough Animations 下 Classic 狼人胸甲袖子错位的问题。

1.3.7 中，月血沸腾会响起一声长长的狼嚎；猎人和银誓守夜人换上新的长风衣造型，银剑和 Alpha 狼人徽章换用新纹理；祭坛侧面和中央祭坛底面改为素面石砖；教程文字也做了修订。新增两个随从进度：首次招募随从，以及随从升至最高阶。新增配置 `preventWerewolfFullMoonSleep`（默认关闭），开启后狼人无法靠睡觉跳过满月。装有 MCA 时，变身玩家的第一人称手臂恢复为狼人手臂。

玩法介绍、其他版本与下载见 [main 分支](https://github.com/R-Eatch/howling-werewolf)。
