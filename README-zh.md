# 月厄狼人 · Fabric 1.21.11

[English](README.md)

这里是《月厄狼人》**Minecraft 1.21.11** 版的源码，分支 `1.21.11-fabric`。此分支在 **1.3.8** 暂停更新。

| | |
|---|---|
| Mod 版本 | **1.3.8** |
| Minecraft Java 版 | 1.21.11 |
| Fabric Loader | 0.20.1 或更新版本 |
| Fabric API | 0.141.6+1.21.11 或更新版本 |
| Java | 21 |

用 `./gradlew build` 构建，JAR 位于 `build/libs/howlingwerewolf-1.3.8-fabric-1.21.11.jar`。服务端和每个客户端需安装同一版本。

玩法介绍、其他版本与下载见 [main 分支](https://github.com/R-Eatch/howling-werewolf)。
