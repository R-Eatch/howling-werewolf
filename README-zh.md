# 月厄狼人 / Howling Werewolf

[English](README.md)

月厄狼人是一款为 Minecraft Java 版独立开发的狼人养成 Mod。玩家可以感染狼人血脉，经历月相变身，通过两套成长系统强化自身，掌握三种可玩形态，并最终挑战头戴月冠的 Alpha 狼人。

本 Mod 受到 Minecraft 社区多个优秀狼人 Mod 的启发而开发构建，但并非任何其他项目的移植、分支、官方续作或官方重制版，也不隶属于或代表其创作者。

## 运行要求

| 项目 | 版本 |
|---|---|
| Minecraft Java 版 | 1.20.1 |
| Mod 加载器 | Forge 47.4.16，或兼容的 Forge 47.x 版本 |
| Java | 17 |
| 月厄狼人 | 1.0.0 |

本 Mod 不需要安装 GeckoLib。多人游戏需要客户端和专用服务器安装相同版本的 Mod。

## 主要内容

- 感染、延迟觉醒、主动变身，以及满月强制变身。
- 普通狼人、四足狼和击败 Alpha 后解锁的野兽形态。
- 独立的狼人等级、技能树技能和主动/被动能力系统。
- 空手利爪战斗、成长伤害与减伤、吸血、长爪、火焰爪、工具爪、血腥撕咬和月血沸腾。
- 野生失控狼人、中立猎人、村庄巡猎队、银制装备、狼毒花和两种对立药水。
- 完整的单人 Alpha 试炼：祭坛结构、猎人阶段、多阶段首领战、重复奖励和永久野兽形态成长。
- 完整英文与简体中文本地化。
- 可配置感染率、经验倍率、最高等级、世界生成、Alpha 受伤间隔、徽章消耗、装备显示和野兽伤害行为。
- 可供数据包扩展的银制武器与狼人食物标签。

## 安装

1. 安装 Minecraft Java 版 1.20.1 和 Forge 47.4.16。
2. 将 `howlingwerewolf-1.0.0.jar` 放入游戏实例的 `mods` 目录。
3. 多人游戏需要在专用服务器与所有客户端安装同一个 JAR。
4. 启动游戏。银矿、狼毒花和自然实体会按照服务端配置出现在符合条件的新生成区块中。

添加或更新任何 Mod 前，建议备份重要世界。

## 开始狼人之路

获得狼人血脉主要有两种方式：

- 承受自然生成的失控狼人攻击并感染。默认感染概率可以配置，感染者会在之后的夜晚觉醒。
- 酿造或获得狼人药水，立即完成觉醒。

觉醒后按 `K` 打开狼人养成界面。主世界满月会强制变身；规则允许时可按 `J` 主动变身或恢复人形。变身状态下击杀生物可以获得狼人经验，并将成长所得点数投入技能树与能力。

狼毒花代表与狼人血脉相反的道路。狼毒花药水可以治愈狼人；猎人使用银剑，并提供可持续获得狼毒花的途径。

## 三种狼人形态

| 形态 | 解锁与切换 | 特点 |
|---|---|---|
| 人形 | 默认状态，或按 `J` 恢复 | 使用普通装备与生存规则，不享受变身加成。 |
| 普通狼人 | 觉醒后按 `J`，或在满月被强制变身 | 均衡的利爪战斗、随等级成长的自然减伤、移速加成和大部分能力。 |
| 四足狼 | 学习“荒野奔行”后按 `G` | 移速和跳跃明显提高，但攻击伤害略低，不能穿戴装备。 |
| 野兽 | 首次完成 Alpha 试炼后按 `H` | 战斗、速度、跳跃和防御显著增强，但饥饿消耗更快，不能穿戴装备。 |

狼人变身后默认不能穿戴护甲或鞘翅。“披甲本能”只允许普通狼人形态穿戴。只有提供正护甲值的装备会削弱该能力提供的自然减伤和移动增益；鞘翅等零护甲装备不会触发削弱。

## 等级、技能树与能力

狼人等级会提高基础利爪伤害和自然减伤。默认最高等级为 20，可配置到 25。

技能树用于强化长期属性和被动效果，包括：

- 利爪伤害与按目标最大生命计算的裂月伤害；
- 自然防御、速度、跳跃、再生、击退抗性和摔落抗性；
- 吸血、饱食控制、利爪距离/抢夺，以及更多狩猎经验。

能力用于解锁新的操作和规则，包括夜视、狼灵召唤、四足狼形态、月血沸腾、披甲本能、扩展饮食、利爪空槽管理、长爪、工具爪、火焰爪和血腥撕咬。

Alpha 狼人徽章放在快捷栏任意位置时具有两种相关但不同的效果：

- 只要拥有狼人血脉，即使处于人形，每分钟也会获得 10 点基础狼人经验；
- 抵挡一次致命伤害还要求玩家已经变身。默认会消耗一枚徽章，可以通过通用配置改为不消耗。

将徽章移出快捷栏会关闭两种效果，并清零尚未完成的一分钟被动经验计时。

## 默认按键

所有按键都可以在 Minecraft 的控制设置中修改。

| 按键 | 功能 |
|---|---|
| `K` | 打开狼人养成界面 |
| `J` | 变身或恢复人形 |
| `G` | 切换四足狼形态 |
| `H` | 切换野兽形态 |
| `V` | 开关狼人自动夜视 |
| `N` | 召唤狼灵 |
| `B` | 使用血腥撕咬 |
| `R` | 释放月血沸腾 |

## 猎人、银与野外遭遇

猎人对普通人类保持中立，对已经变身的狼人敌对。他们会以很低的权重单独出现在森林群系，也会在玩家到访的村庄周围组成 4–6 人的持久巡猎队。村庄首次达到目标人数后，死亡缺员可以在一个 Minecraft 日冷却后逐名补充。

银剑攻击会对狼人造成额外伤害并施加虚弱。普通猎人至少掉落一株狼毒花，并有概率额外掉落一株。

失控狼人只会在主世界符合条件的森林中，于黑暗的满月夜自然生成。严格的条件使其成为危险而少见的遭遇，而不是日常刷新的普通敌对生物。

## Alpha 试炼

Alpha 试炼是第一阶段狼人养成的终局挑战。

1. 达到狼人 10 级，并准备一座中央仪式祭坛、四座普通仪式祭坛、一枚 Alpha 狼人徽章和四颗月厄珍珠。
2. 将四座普通祭坛放在中央祭坛的四个正方向，相距正好三格，并保持相同高度。
3. 在中央祭坛献上徽章，在四座外侧祭坛各献上一颗珍珠。
4. 于主世界夜间、普通狼人形态下开始仪式；结界只允许一名玩家参与。
5. 先击败强化猎人，再挑战月冠 Alpha 狼人。

首次胜利会永久解锁野兽形态并给予对应成长奖励。重复胜利会根据难度奖励月厄珍珠；困难难度还会提供额外技能点与技能树点。

## 配置与数据包

Forge 通用配置包括：

- 普通狼与失控狼人的感染概率；
- 狼人经验倍率和最高等级；
- 银矿与狼毒花世界生成；
- 野兽形态虚空伤害行为；
- Alpha 试炼受伤频率限制；
- 徽章复生是否消耗徽章；
- 普通狼人模型是否显示装备。

数据包可以扩展以下物品标签：

- `howlingwerewolf:silver_weapons`
- `howlingwerewolf:werewolf_meat`

## 从源码构建

本仓库使用 Gradle Wrapper，目标字节码版本为 Java 17。

Windows：

```bat
gradlew.bat clean build
```

Linux 或 macOS：

```bash
./gradlew clean build
```

重混淆后的发行 JAR 位于 `build/libs/`。首次构建可能需要下载 Forge 与 Minecraft 开发依赖。
