# 月厄狼人 · Fabric 26.3

[English](README.md)

这里是《月厄狼人》**Minecraft 26.3** 版的源码，分支 `26.3-fabric`。

| | |
|---|---|
| Mod 版本 | **1.4.4** |
| Minecraft Java 版 | 26.3 |
| Fabric Loader | 0.20.1 或更新版本 |
| Fabric API | 0.166.2+26.3 或更新版本 |
| Java | 25 |

用 `./gradlew build` 构建，JAR 位于 `build/libs/howlingwerewolf-1.4.4-fabric-26.3.jar`。服务端和每个客户端需安装同一版本。

v1.4.4 将首领治疗喊话间隔调为 60 秒，并新增下界、末地、村庄和狼人部落的随从入场对白。每次进入时随机播报一句，同一段停留只播报一次。 此版本也修复了部落花箱、箱中战利品、猎人掉落和名牌，以及飞扑提示变色。

玩法介绍、其他版本与下载见 [main 分支](https://github.com/R-Eatch/howling-werewolf)。
