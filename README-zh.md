# 月厄狼人 · NeoForge 1.21.1

[English](README.md)

这里是《月厄狼人》**Minecraft 1.21.1** 版的源码，分支 `1.21.1-neoforge`。

| | |
|---|---|
| Mod 版本 | **1.4.7** |
| Minecraft Java 版 | 1.21.1 |
| NeoForge | 21.1.248 或更新的 21.1.x |
| Java | 21 |

用 `./gradlew build` 构建，JAR 位于 `build/libs/howlingwerewolf-1.4.7-neoforge.jar`。服务端和每个客户端需安装同一版本。

v1.4.7 扩大野性飞跃的落地范围和选点距离，落地伤害受利爪伤害技能倍率影响，满级野兽免疫 generic_kill。Modern 玩家模型增加尾巴摆动，预览使用玩家皮肤与外层显示设置。银鞣皮每件减免 10% 狼人与冰冻伤害，全套另获 10% 减伤。部落房屋增加后门，祭坛入口改为木梁雕石门廊，部落居民与酋长共用失控狼人的感染概率配置。

教程、随从指南与既有对白采用新版中英文润色文本，狼人酋长和守月人队长各新增三段随机闲谈。

玩法介绍、其他版本与下载见 [main 分支](https://github.com/R-Eatch/howling-werewolf)。
