## 当第一声嚎叫尚未响起

森林里留下的一道爪伤，起初或许和其他伤口没有区别。直到又一个夜晚来临，沉睡的血脉开始苏醒，月亮替你作出了第一次选择。

最初，成为狼人是一场需要熬过去的意外；此后，它才逐渐成为一种可以掌握的力量。你会学着分辨何时顺从满月、何时凭自己的意志变身，也会在一次次狩猎中磨利爪牙、唤醒新的本能，最终以四足踏过荒野。

当你的力量足够强大，开启月誓仪式，进入 Alpha 试炼，Alpha 会决定你是否有资格唤醒血脉深处的野兽。

**月厄狼人（Howling Werewolf）** 是一款为 Minecraft Java 版独立开发的狼人变身与成长 Mod。它把感染、觉醒、月相变身、等级成长、技能树、可学习技能、三种狼人形态、猎人与银制武器、狼毒花，以及最终的 Alpha 试炼连接成一段完整的生存旅程。

本 Mod 受到 Minecraft 社区多个优秀狼人 Mod 的启发，但从代码、玩法系统到项目内容均独立开发。它并非任何其他项目的移植、分支、官方续作或官方重制版，也不隶属于或代表其创作者。

## 这段旅程会怎样开始

1. **狼人血脉的侵入。** 遭遇失控狼人或森林中的狼并在攻击中受到感染，等待之后的夜晚完成觉醒；也可以通过狼人药水立即踏上这条路。
2. **升级与技能成长路线** 按 `K` 打开狼人进阶界面，在这里查看等级、技能树、可学习技能、形态说明和月誓仪式。
3. **学会控制变身。** 当前规则允许时，按 `J` 可以变身或恢复人形；月圆高悬，狼人的血脉让你无法控制自己的形态。
4. **向旧日 Alpha 发起挑战。** 按进阶界面中的说明构筑月誓仪式，击败守夜人与月冠 Alpha，最终唤醒野兽形态。

## 狼人皮肤与自定义皮肤

默认按 **K** 打开狼人菜单 → **皮肤**，在右上角切换 **Classic / Modern**，选择皮肤并点击**应用**保存。Classic 保留原棕色 **Adrian**、琥珀眼灰狼 **Ashen**、金眼黑狼 **Onyx** 与红眼白狼 **Ivory**；Modern 提供九套配色，每套均覆盖普通狼人、四足狼和野兽三种形态。

新玩家默认使用 **Modern / Ashen**；已有 Classic 选择和缺少模型字段的旧存档继续按 Classic 读取。预览支持鼠标跟随、拖动旋转、滚轮缩放和装备显示开关；预览不会解锁或切换实际形态。模型系列和皮肤逐玩家保存，死亡、换维度、重置等级以及治愈后再觉醒均保留，第三人称、背包预览与第一人称爪使用相应外观。

在皮肤页选择**创建模板**，即可导出当前模型系列的 PNG、Blockbench 绘画模板和资源包说明。Modern 模板跟随选中的内置配色；从自定义皮肤导出时使用 Ashen。导出自己的 PNG，启用对应资源包，再按 **F3 + T** 重载资源，就能在皮肤界面选择作品。

联机同步每名玩家的模型系列和皮肤 ID，不会自动上传图片。内置皮肤无需额外资源包；自定义皮肤需要观察者启用相同资源包，缺失时按系列回退到 Classic Adrian 或 Modern Ashen，保存的选择仍然保留。各游戏版本的资源包格式不同，请使用对应分支的模板。

完整教程见[自定义皮肤指南](CUSTOM_SKINS-zh.md)（[English](CUSTOM_SKINS.md)）。

## 安装

1. 选择所需的 Minecraft 版本，安装对应的 Forge、NeoForge 或 Fabric 加载器（Fabric 还需要 Fabric API）及所需 Java。
2. 从 [GitHub Releases](https://github.com/R-Eatch/howling-werewolf/releases)、[Modrinth](https://modrinth.com/mod/howling-werewolf) 或 [CurseForge](https://www.curseforge.com/minecraft/mc-mods/howling-werewolf) 下载与该版本对应的 Mod JAR，放入游戏的 `mods` 目录。
3. 启动游戏。联机时客户端与服务端应安装对应游戏版本的相同 Mod 版本。

添加或更新任何 Mod 前，建议先备份重要世界。

## 最初的几个夜晚

获得狼人血脉主要有两种方式：

- 承受森林里的野生狼或狼人攻击并感染。默认感染概率可以配置，感染者会在之后的夜晚觉醒。
- 酿造或获得狼人药水，饮用后立即完成觉醒。

觉醒后，在血脉规则允许时按 `J` 可以变身或恢复人形；主世界的满月则会强制狼人变身，即使你并不想在那个夜晚显露兽性。

变身状态下击杀生物可以获得狼人经验。随着等级提升，你可以将成长所得投入技能树与新的能力。

不知道下一步该做什么时，按 `K` 打开狼人进阶界面即可。这里不仅记录等级与成长进度，也集中提供技能树、主动与被动技能、形态解锁条件，以及开启 Alpha 试炼所需的月誓结构、条件与奖励。

狼毒花代表与狼人血脉相反的道路。狼毒花药水可以治愈狼人；猎人使用银剑，并提供可持续获得狼毒花的途径。

## 狼人形态

| 形态 | 解锁与切换 | 特点 |
|---|---|---|
| 人形 | 默认状态，或按 `J` 恢复 | 使用普通装备与生存规则，不享受变身加成。 |
| 普通狼人 | 觉醒后按 `J`，或在满月被强制变身 | 利爪战斗、随等级成长的自然减伤、移动加成，以及大部分狼人能力。 |
| 四足狼 | 学习“荒野奔行”后按 `G` | 移速和跳跃明显提高，但攻击伤害略低，不能穿戴装备。 |
| 野兽 | 首次完成 Alpha 试炼后按 `H` | 战斗、速度、跳跃和防御显著增强，但饥饿消耗更快，不能穿戴装备。 |

狼人变身后默认不能穿戴护甲或鞘翅。**披甲本能** 只允许普通狼人形态穿戴装备。装备默认显示，可以在皮肤页用“装备”开关切换，随皮肤一起应用并同步给其他玩家；配置项 `showWerewolfEquipment=false` 会在本机隐藏所有狼人的装备。

只有提供正护甲值的装备会削弱该能力提供的自然减伤和移动增益；鞘翅等零护甲装备不会触发这一削弱。

## 等级、技能树与技能

狼人等级会提高基础利爪伤害和自然减伤。默认最高等级为 20，可配置到 25。

技能树用于强化长期属性和被动效果，包括：

- 利爪伤害与按目标最大生命计算的裂月伤害；
- 自然防御、速度、跳跃、再生、击退抗性和摔落抗性；
- 吸血、饱食控制、利爪距离/抢夺，以及更多狩猎经验；
- 狼群誓约：决定随从名额和最高阶数。

能力用于解锁新的操作和规则，包括：

- 夜视；
- 狼灵召唤；
- 荒野奔行 / 四足狼形态；
- 月血沸腾；
- 披甲本能；
- 扩展饮食；
- 利爪空槽管理；
- 长爪；
- 工具爪；
- 火焰爪；
- 血腥撕咬。

长爪、工具爪和火焰爪学会后，可以在技能页随时关闭或重新开启，不消耗也不退还技能点。

### Alpha 狼人徽章

Alpha 狼人徽章放在快捷栏任意位置时具有两种效果：

- 只要拥有狼人血脉，即使处于人形，每分钟也会获得 **10 点基础狼人经验**；
- 抵挡一次致命伤害还要求玩家已经处于变身状态。

默认情况下，致命伤害保护会消耗一枚徽章；这一行为可以通过通用配置调整。

将徽章移出快捷栏会关闭两种效果，并清零尚未完成的一分钟被动经验计时。

## 猎人、银、狼毒花、月厄珍珠与野外遭遇

猎人对普通人类保持中立，对已经变身的狼人敌对。

他们会以很低的权重单独出现在森林群系，也会在玩家到访的村庄周围组成 **4–6 人** 的持久巡猎队。村庄首次达到目标人数后，死亡缺员可以在一个 Minecraft 日冷却后逐名补充。

银剑攻击会对狼人造成额外伤害并施加虚弱。普通猎人至少掉落一株狼毒花，并有概率额外掉落一株，且有低概率掉落银锭。

狼毒花自然生成在森林群系，稳定的获取方式仍为击杀出现在村庄的猎人巡猎队。

失控狼人只会在主世界符合条件的森林中，于黑暗的满月夜自然生成。严格的生成条件使其成为危险而少见的遭遇。

月厄珍珠由末影珍珠和狼毒花合成，用于月誓，也可用于合成狼人徽章。

## 月誓与 Alpha 试炼

Alpha 试炼是狼人养成的终局挑战。

按 `K` 打开狼人进阶界面后，可以随时查看月誓页面；祭坛布局、进入条件、所需祭品和挑战奖励都记录在其中。

1. 达到狼人 10 级，并准备一座月誓中央祭坛、四座普通月誓祭坛、一枚 Alpha 狼人徽章和四颗月厄珍珠。
2. 将四座普通祭坛放在中央祭坛的四个正方向，相距正好三格，并保持相同高度。
3. 在中央祭坛献上徽章，在四座外侧祭坛各献上一颗珍珠。
4. 于主世界夜间、普通狼人形态下开始仪式。该试炼每次只为一名参与玩家设计。
5. 先击败强化猎人，再挑战月冠 Alpha 狼人。

首次胜利会永久解锁野兽形态，并给予对应的成长奖励。

重复胜利会根据难度奖励月厄珍珠；困难难度下还会提供额外技能点与技能树点。

## 打不过Alpha试炼？ 这是作者的参考攻略：

Alpha 试炼在狼人 **10 级**时开放，但解锁的野兽形态十分强大，因此挑战难度也相应较高。不同游戏难度下，Boss 的生命值和战斗阶段会有所不同；首次在任意难度完成试炼，都能解锁野兽形态。

### Alpha 的招式

1. **普通攻击：** 对近身目标发动近战攻击。
2. **召唤：** 周期性召来会施加减益效果的随从；首次降至半血和复活后，还会安排额外召唤。Alpha 在召唤吟唱时暂停攻击，是集中输出的机会，但仍需留意场上的随从。
3. **瞬闪步：** 瞬移到玩家身后，尝试发动附带减益效果的高伤害突袭。不要把血量压得过低，要为这次攻击留出余量。
4. **游猎：** 仅在复活前存在。Alpha 每次成功近战命中后，有 **25%** 的概率向后走位，尝试避开玩家的攻击。这段后撤会留出喘息时间，也能减轻持续近战带来的血量压力。
5. **复活：** 仅普通和困难难度存在，恢复的血量随难度变化。复活后不再游猎，战斗压力会进一步上升。

### 简单与普通难度：等级和配点

建议达到 **15 级（简单）**或 **18 级（普通）**后再挑战，并提前做好以下配点：

- **技能树：** 将利爪伤害、裂月利爪、自然防御、再生和吸血升满；速度、击退抗性、抗性和狼爪效率尽量提高。
- **技能：** 学会夜视、月血沸腾、血腥撕咬、狼爪为空和长爪。

### 困难难度：建议 20 级后挑战

困难难度面向后期成长，Boss 的加成和复活阶段都更具威胁。以下打法也同样适配简单和普通难度：

1. **猎人阶段：** 利用长爪的范围伤害，配合移动处理成群猎人，减少被围攻的机会。
2. **Alpha 阶段起手：** 先用血腥撕咬施加虚弱 II，趁减益生效时集中输出，争取先削去约五分之一到四分之一的 Boss 血量。
3. **衔接月血沸腾：** 根据自己的血量，在血腥撕咬的减益即将结束时开启月血沸腾，利用强力恢复、伤害吸收和抗性增益继续进攻，争取在增益期间结束战斗。
4. **准备下一轮：** 如果增益结束后 Boss 仍然存活，先稳住血量和走位，待血腥撕咬冷却完成后再补上减益，寻找下一次输出机会。多练习招式节奏，也可以尝试下落暴击：满足原版暴击条件时，基础近战伤害有 **1.5 倍**加成。

还可以灵活运用吸血，在场地内预留一些可攻击的生物，必要时通过攻击或击杀它们补充生命。准备金苹果、不死图腾、Alpha 狼人徽章及其他恢复道具，也能增加容错；徽章需要放在快捷栏中，并在狼人变身状态下才能抵挡致命伤害。

三个难度的推荐等级和配点我已经在游戏里完成过实际的战斗测试，并击败了Alpha，各位玩家可以通过多加练习来通过挑战，祝各位玩家顺利击败Alpha !

### 逃课打法

虽然我不建议大家使用如下方式，这会丢失部分游戏体验，但我也提供了相对应的作战策略

- **先解锁，再挑战高难度：** 先在简单难度击败 Alpha，解锁野兽形态后，再用野兽形态挑战普通或困难难度。
- **尝试利用场地：** 搭建仅容两格高通行的遮挡平台，站在下面限制 Boss 的近身空间，思路类似应对末影人。可以根据瞬闪位置和场地布局继续调整。
- **使用船** 使用船控制住 Alpha ，正如强迫末影人坐在船上一样（可怜的Alpha被羞辱般的困在船上肆意玩弄，我没有禁止Alpha乘坐船也是考虑了部分玩家的逃课需求，不过也许我会在后续更新中让Alpha不能再被船困住 :> ）
- **按自己的节奏调整配置：** 配置中提供了默认关闭的强力可选参数，例如复活保留徽章。部分参数可以明显降低挑战压力，适合希望轻松体验或练习打法的玩家。

## 狼人兄弟：商人与随从

月誓祭坛不只用来挑战 Alpha。换一组供品，就能召来一位游荡的狼人兄弟。

**召唤**

1. 在技能树中学会 **狼群誓约**。
2. 按月誓的布局摆好五座祭坛：中央一座，东南西北各隔三格一座，五座同高。
3. 四座外坛各放一朵 **狼毒花**，中央放一颗 **月厄珍珠**，空手右键中央祭坛。

| 仪式 | 中央 | 四座外坛 |
|---|---|---|
| 召唤狼人兄弟 | 月厄珍珠 | 狼毒花 |
| Alpha 试炼 | 狼人徽章 | 月厄珍珠 |

召唤不限昼夜和月相。狼人兄弟会从远处赶到你身边，停留十分钟。

**交易**：普通右键打开交易。每位商人从九种交易里抽六种，涉及银锭、狼毒花、月厄珍珠、狼人药水和狼毒花药水，次数有限、不补货。

**招募**：手持狼人徽章右键商人并确认，消耗一枚徽章，他就成为你的长期同伴。通过 Alpha 试炼前最多一名随从；通过后，狼群誓约每升一级多一个名额，最多三名。随从的最高阶数等于狼群誓约的等级。

**指令**（按 **C** 打开随从窗口，右键随从也可以打开并选中它）：

| 指令 | 说明 |
|---|---|
| 跟随 | 紧跟在你身边，跨维度也会回来。怪物会忽略它。 |
| 守护 | 与你并肩作战：协助你攻击、保护受击的你，也会反击。 |
| 休息 | 留在原地等候。怪物会忽略它。 |
| 整理 | 亲自走动，归整半径 16 格内的箱子和木桶。挂上放了物品的展示框可以指定容器存放什么；陷阱箱和潜影盒不参与。 |
| 狩猎 | 外出 1.5–3 个 MC 日，带回肉、毛皮、矿物等收获；结束后休整两天。 |

此外还可以在任意维度 **召回**、用月厄珍珠 **升阶**（最高 3 阶，提高生命、伤害、减伤和恢复）、用狼人徽章 **复活**、改名换毛色、打开九格背包，以及确认后 **遣散**（背包物品交还给你）。

完整说明见[随从指南](docs/COMPANIONS-zh.md)和[狩猎与交易表](docs/COMPANION-TABLES-zh.md)。

## 配置与数据包

各版本的通用配置中可以调整感染率、经验倍率、最高等级等多个参数，你可以根据自己的喜好来改变整段狼人旅程的节奏。

配置文件：`config/howlingwerewolf-common.toml`（Fabric 版为 `config/howlingwerewolf-common.json`）。

随从相关：`gameplay.enableCompanions`（默认 true）统一开关随从；`gameplay.enableCompanionSorting`（默认 true）单独开关整理；`gameplay.companionSortingReach`（默认 32，3–64）是随从走不到跟前时仍能整理的最远距离。界面的月白／夜幕选择保存在客户端文件 `config/howlingwerewolf-client.toml`（Fabric 为 `.json`）。

涉及世界生成或已有存档的设置应谨慎修改；进行较大调整前，建议先备份重要世界。

数据包可以扩展以下物品标签：

- `howlingwerewolf:silver_weapons`
- `howlingwerewolf:werewolf_meat`

服务器管理员与测试人员可以查阅[管理员命令指南](ADMIN_COMMANDS-zh.md)，该文档也提供[英文版本](ADMIN_COMMANDS.md)。
