# 月厄狼人 · NeoForge 26.1.2

[English](README.md)

这里是《月厄狼人》**Minecraft 26.1.2** 版的源码，分支 `26.1.2-neoforge`。

| | |
|---|---|
| Mod 版本 | **1.5.0** |
| Minecraft Java 版 | 26.1.2 |
| NeoForge | 26.1.2.122 或更新的 26.1.2.x |
| Java | 25 |

用 `./gradlew build` 构建，JAR 位于 `build/libs/howlingwerewolf-1.5.0-neoforge-26.1.2.jar`。服务端和每个客户端需安装同一版本。

v1.5.0 整合荒野狼人部落（5 套群系共 40 个模板）与村庄猎人前哨（4 套群系共 12 个模板，移除旧版兼容模板）、野性飞跃（双足基础伤害 7、野兽 10，冷却 15 秒）、召唤狼灵 120 秒冷却、银鞣皮甲、银誓猎弩、Modern 玩家模型、新版润色双语教程与台词，以及阵营加权交易（守月人 2:1 倾向银锭/狼皮且药水仅出狼毒花药水；酋长 2:1 倾向狼毒花/月厄珍珠且药水仅出狼人药水；狼人商人不变）。

玩法介绍、其他版本与下载见 [main 分支](https://github.com/R-Eatch/howling-werewolf)。
