# 月厄狼人 · NeoForge 26.1.2

[English](README.md)

这里是《月厄狼人》**Minecraft 26.1.2** 版的源码，分支 `26.1.2-neoforge`。

| | |
|---|---|
| Mod 版本 | **1.3.8** |
| Minecraft Java 版 | 26.1.2 |
| NeoForge | 26.1.2.122 或更新的 26.1.2.x |
| Java | 25 |

用 `./gradlew build` 构建，JAR 位于 `build/libs/howlingwerewolf-1.3.8-neoforge-26.1.2.jar`。服务端和每个客户端需安装同一版本。

1.3.5–1.3.7 新增分章节的“教程”页（含物品介绍与配方）、每位随从单独的“不受主人伤害”开关、月血沸腾同时作用于附近随从、Modern 模型下 Alpha 试炼的随机毛色，并优化原版盔甲贴合、兼容 MCA。月血沸腾会响起一声长长的狼嚎；猎人和银誓守夜人换上新的长风衣造型；银剑和 Alpha 狼人徽章换用新纹理；祭坛侧面和中央祭坛底面改为素面石砖；新增两个随从进度：首次招募随从，以及随从升至最高阶。新增配置 `preventWerewolfFullMoonSleep`（默认关闭），开启后狼人无法靠睡觉跳过满月。

玩法介绍、其他版本与下载见 [main 分支](https://github.com/R-Eatch/howling-werewolf)。
