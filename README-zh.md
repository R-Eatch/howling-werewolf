# 月厄狼人 · NeoForge 26.1.2

[English](README.md)

这里是《月厄狼人》**Minecraft 26.1.2** 版的源码，分支 `26.1.2-neoforge`。

| | |
|---|---|
| Mod 版本 | **1.3.8** |
| Minecraft Java 版 | 26.1.2 |
| NeoForge | 26.1.2.122 或更新的 26.1.2.x |
| Java | 25 |

用 `./gradlew build` 构建，JAR 位于 `build/libs/howlingwerewolf-1.3.8-neoforge-26.1.2.jar`。服务端和每个客户端需安装同一版本。

玩法介绍、其他版本与下载见 [main 分支](https://github.com/R-Eatch/howling-werewolf)。
