# 随从与 Beast：1.2.7

适用于 Minecraft 26.1.2、NeoForge 26.1.2.122、Java 25。客户端和服务端都需更新至 1.2.7，网络协议为 17。[English](COMPANIONS-1.2.7.md)。

这一版让随从真正动手干活：它会走到箱子前打开盖子、拿起物品、走到目标容器放下。随从界面整体重做，教程全部重写，Modern Beast 换上了参考狼和虎的奔跑步态。祭坛、商人、招募、背包、狩猎、升级与复活的规则保持不变，详见游戏内教程和 [1.2.4 指南](COMPANIONS-1.2.4-zh.md)。

## 整理

### 怎么用

1. 把随从带到仓库中央，按 C 打开窗口，切到“整理”页。
2. 点“开始整理”。

就这两步，不需要逐个登记容器。工作范围是**以随从开始时的位置为中心、半径 16 格的球形区域**，工作中心不会随着它走动而改变。范围内的原版箱子、陷阱箱、铜箱和木桶都会纳入，最多照看最近的 64 个，双箱算一个。

随从接下来会这样干活：

1. 走到容器前，打开盖子（真实的开盖动画和音效，陷阱箱也会照常发出信号）。
2. 把要搬的物品拿在手里，合上盖子。
3. 走到目标容器，打开盖子放下，再合上。

干完一轮后，它会告诉你一声，然后留在原地继续照看，之后放进来的东西也会被归整。下达其他指令即可结束。

### 两种方式

| 方式 | 效果 |
|---|---|
| 同类集中（默认） | 把同种物品集中到原本存放它最多的容器，放不下的部分留在其他容器。 |
| 仅合并堆叠 | 只填满已有的零散堆叠，空格保持原样。 |

物品类型和全部数据组件都相同才算同一种：名称、耐久、附魔、药水内容不同的物品各自分开。装备等不可堆叠的物品留在原处。

### 物品安全

手里拿着的物品只是显示效果，真正的转移发生在放下的那一刻，并在 NeoForge 事务中一次完成。所以随时停止、随从阵亡或服务器重启，物品都还在原来的容器里。放不下的物品留在原处，整理不会把物品丢到地上。

### 哪些容器会被跳过

雷达图上灰色的点就是暂时跳过的容器，鼠标移上去可以看到坐标：

- 正被其他玩家打开的容器；
- 上锁、盖子被挡住或受交互保护的容器；
- 尚未开启过的战利品箱；
- 随从走不到的容器（一分钟后会再试一次）。

其余容器照常整理。保护检查包括原版出生点和访问限制，以及 NeoForge 右键交互事件的拒绝结果。领地插件是否通过此事件拦截，需要结合具体插件验证。

### 暂停与多人

主人下线或离开这个维度时工作暂停，回来后继续。随从被带离工作范围太远时也会暂停。整理不会强制加载区块，也不跨维度读取容器。只有主人能启动和调整，反馈和对白也只发给主人。

### 服务器配置

```toml
[gameplay]
enableCompanionSorting = true
```

设为 `false` 只关闭整理，其他随从功能照常。从 1.2.6 升级时，旧存档可以直接读取，之前登记的容器名单不再使用。

## 全新的随从界面

一个窗口、四个页签，切换时不丢失当前选中的随从：

- **狼群**：左边是随从名册，中间是实时形象，右边是状态和指令。鼠标移到指令上就能看到说明；按钮不可用时会告诉你原因，比如“还需 0.75 个 MC 日”。
- **整理**：实时雷达图显示工作范围内的每个容器和随从当前的目标，旁边是进度条和整理方式。
- **外观**：所有毛色一键预览，满意后再应用。
- **教程**：章节导航加可滚动的阅读页，底部可以翻到上一章或下一章。

小技巧：数字键 1–5 直接下令，↑↓ 切换随从。

## Modern Beast 奔跑与下蹲

冲刺改为参考狼和虎的旋转式奔跑：后腿一前一后蹬地发力，身体伸展腾空，前腿依次落地接住重量，四肢再收拢到弯曲的脊柱下方。身体前后起伏，视线始终保持水平，尾巴在身后舒展。起跳时四肢前后张开。

下蹲时 Beast 会四足着地，放低身形，移动时四条腿按潜行的步序依次抬起。使用弓、盾这类物品时仍保持直立姿势，便于瞄准。第一人称下蹲的视角相应降低；碰撞箱没有变化。Classic 模型的动作保持原样。

## 随从挥手

随从攻击时现在会挥动手臂。这个问题的根源是原版只为怪物和玩家推进挥手计时，随从继承自村民一类，计时一直没有走动。

## 管理员命令

新增 `/werewolf unlockalpha <target> [state]`，一条命令解锁 Alpha：省略 `state` 或设为 `true` 时，目标成为狼人并永久解锁野兽形态和 Alpha 相关的随从名额；`false` 撤销解锁。它不发放徽章，也不播放试炼奖励。详见[管理员命令指南](../ADMIN_COMMANDS-zh.md)。
