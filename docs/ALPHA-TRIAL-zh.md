# Alpha 试炼数值

[English](ALPHA-TRIAL.md) · [返回 README](../README-zh.md)

本页只列数值，适用于 1.3.8 的全部五个版本。仪式流程和打法见 README 的“月誓与 Alpha 试炼”。

下表中的伤害是生物的攻击属性。原版还会按游戏难度调整生物对玩家的伤害：简单约为一半再加 1，普通不变，困难 ×1.5。

## 开始条件

| 条件 | 数值 |
|---|---|
| 维度 | 主世界 |
| 时间 | 夜晚，一天中的 13000–22999 刻 |
| 狼人等级 | 10 级及以上 |
| 形态 | 普通狼人形态（不能是四足狼或野兽） |
| 人数 | 结界半径 18 格内没有其他玩家 |
| 祭坛 | 中央祭坛放 Alpha 狼人徽章，东南西北相距 3 格的四座祭坛各放 1 颗月厄珍珠，五座同高 |
| 游戏难度 | 不能是和平 |

## 阶段

| 阶段 | 数值 |
|---|---|
| 仪式启动 | 12 秒 |
| 结界 | 以中央祭坛为圆心、水平半径 18 格。挑战者靠近边缘会被推回；其他玩家被推出；试炼猎人被拉回场内。 |
| 第一阶段 | 7 名银誓守夜人，在半径 8 格处出现。全部击杀后进入第二阶段。 |
| 第二阶段 | 月冠 Alpha 狼人 |

## 失败条件

以下任一情况立即失败：

- 挑战者离线、死亡或离开当前维度；
- 挑战者离中央祭坛超过 18.5 格；
- 五座祭坛中任意一座被破坏；
- 游戏难度改为和平。

失败时中央的 Alpha 狼人徽章作为掉落物返还，四颗月厄珍珠不返还；场上的守夜人、Alpha 和召唤狼人全部移除。

|---|---|
| 数量 | 7 |
| 生命 | 30 |
| 护甲 | 4 |
| 基础攻击 | 3，手持银剑（与铁剑同级） |
| 移动速度 | 0.27 |
| 常驻效果 | 力量 I、速度 I、生命恢复 I、抗性提升 I、发光 |

| 掉落 | 1 朵狼毒花，50% 再掉 1 朵；不掉落普通战利品，银剑不掉落 |

|---|---:|---:|---:|
| 最大生命 | 300 | 400 | 400 |
| 攻击 | 19 | 21 | 25 |
| 复活 | 无 | 恢复到 20%（80） | 恢复到 42%（168） |

| 共同属性 | 数值 |
|---|---|

| 追踪范围 | 48 格 |

### 招式

| 招式 | 数值 |
|---|---|
| 普通攻击 | 每 2 秒尝试一次近战，攻击距离比普通生物远 2 格。 |
| 游猎（复活前） | 近战命中后有 25% 几率后撤 6 秒，始终面向玩家；前 3 秒获得速度 III。 |
| 瞬闪步 | 出手前 1 秒预警，瞬移到玩家身后 2 格，造成攻击 ×1.25 的伤害，并施加缓慢 I 10 秒。约每 20 秒一次，复活后约每 15 秒一次。 |
| 召唤 | 吟唱 5 秒，期间不移动、不攻击；结束时在身边召出 4 只狼人。Alpha 阶段一开始召唤一次，之后每 45 秒一次（从吟唱开始计时）。首次降到 50% 生命和复活后各追加一次，但仍要等 45 秒冷却。 |
| 复活（普通、困难） | 第一次致命伤害被抵消，生命恢复到上表比例；获得生命恢复 II、抗性提升 I 各 60 秒，力量升为 II，瞬闪冷却缩短为 15 秒，不再游猎，并追加一次召唤。 |

### 召唤的狼人

| 属性 | 简单 / 普通 | 困难 |
|---|---:|---:|
| 生命 | 40 | 40 |
| 攻击 | 6 | 9 |

- 移动速度 0.30，击退抗性 0.20。
- 常驻力量 I、速度 I、发光；出现后 30 秒内有抗性提升 I。
- 受到的伤害 ×0.9（无视无敌时间的伤害除外）。
- 命中时施加饥饿 II 15 秒、中毒 II 5 秒。
- 会攻击任何玩家，但不会感染玩家；击杀没有原版经验，也没有战利品。
- 试炼失败时移除；击败 Alpha 后仍在场的召唤狼人不会消失。

## 奖励

| 情况 | 奖励 |
|---|---|
| 首次胜利（任意难度） | 永久解锁野兽形态，另得 1 瓶狼人药水、1 颗月厄珍珠、1 枚 Alpha 狼人徽章 |
| 重复胜利：简单 / 普通 | 1 颗月厄珍珠 |
| 重复胜利：困难 | 2 颗月厄珍珠、1 点技能点、1 点技能树点 |

背包满时奖励掉在挑战者脚下。重置进阶会清空困难难度获得的额外点数，见[等级与技能数值](PROGRESSION-zh.md#重置)。
