# 随从玩法：1.2.5

面向 Minecraft 26.1.2 / NeoForge 26.1.2.122。完整基础规则见 [1.2.4 随从指南](COMPANIONS-1.2.4-zh.md)；本页覆盖新的入口、交互和多人规则。基础指南中旧版 L 按键及旧界面说明以本页为准。

- 默认 **C** 打开总控，可重新绑定。旧安装保留 options.txt 中的旧绑定，需在控制选项改为 C 或恢复默认。K 菜单“随从”位于技能树上方，按钮不显示按键。
- 右键自己的随从打开单体控制，预览外观，调整名字和毛色；潜行右键直接打开九格背包。总控中的原有指令和背包入口保留。
- 页面右上角“教程”集中介绍祭坛召唤、十分钟商人、徽章招募、各模式、九格背包、狩猎、升级和复活。
- 中文默认称呼为“主人”。在总控设置最多 16 个字符的称呼，对所有自己的随从生效；清空恢复语言默认。英文默认仍为 my lord。
- 随从对白仅归属玩家收到，不向附近玩家广播。
- 跟随不反击，并拒绝敌对怪物主动选定随从；切换跟随时清除已有怪物仇恨。跟随不是伤害免疫：范围伤害、环境及玩家直接攻击仍可能伤害随从。危险环境优先使用守护。
- 狩猎时长、三日冷却、物品表及升级费用保留；服务器 enableCompanions 开关继续有效。

现代化中英文文案见 [审阅草案](DRAFT-COMPANION-DIALOGUE-MODERN-zh-en.md)，箱子整理见 [设计草案](DRAFT-COMPANION-CHEST-SORTING.md)。两者在 1.2.5 均未实装。

客户端与服务端均需 1.2.5，网络协议 15。
